# DizzDer — Код. Форма. Характер.

Персональное портфолио Қанатұлы Қуат. Полностью новая редакционная композиция: тёплая бумажная палитра, крупная типографика, оранжевая процедурная скульптура и девять проектов с визуальными карточками.

**Сайт:** https://dizzder.github.io/mywebku/

## Что работает

- Интерактивная Canvas-скульптура: вращение указателем, три формы, пауза.
- Автоматическая остановка анимации вне экрана и в фоновой вкладке; поддержка `prefers-reduced-motion`.
- Фильтры C++ / Backend / Web / Android / Tools и доступные диалоги проектов с возвратом фокуса.
- Адаптивная навигация и мобильная версия.
- Прямые контакты и копирование email с честным fallback при недоступном Clipboard API.
- Семантический HTML, skip-link, focus-visible, live regions и рабочая основная страница без JavaScript.

## Запуск

Статический сайт без сборки, npm и runtime-зависимостей. Достаточно любого HTTP-сервера в корне репозитория:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000. Можно открыть `index.html` напрямую; Clipboard API при этом может быть недоступен, и сайт покажет адрес для ручного копирования.

## Структура

- `index.html` — контент и доступная структура.
- `styles.css` — дизайн, состояния и адаптив.
- `app.js` — фильтры, диалоги, навигация, контакты и процедурная графика.
- `assets/favicon.svg` — оригинальная иконка.
- `tests/site.test.cjs` — проверки контента, локальных ссылок и структуры.
- `docs/design.md` — обоснование дизайна и референсы.

Контент карточек в HTML, расширенные описания в объекте `projects` в `app.js`. Визуальные схемы проектов иллюстративные, не являются интерфейсами сервисов или живыми метриками. Сайт не отправляет формы, не собирает аналитику и не использует cookie.

Шрифты Manrope и Space Grotesk загружаются через Google Fonts; при отсутствии сети используются системные шрифты. Контакты сохранены из предыдущей версии сайта. Существующий `qr-code.png` сохранён.

## Проверка

```sh
node --test tests/site.test.cjs
node --check app.js
```

Ручная проверка: мобильное меню, фильтры, все девять диалогов, Escape и возврат фокуса, ссылки, копирование email, пауза/смена формы, отсутствие горизонтальной прокрутки на мобильном экране.

## Публикация

GitHub Pages: ветка `main`, папка `/ (root)`. HTML, CSS, JavaScript и SVG используют относительные пути, поэтому сайт работает в `/mywebku/`. Домен и контакты не меняются.
