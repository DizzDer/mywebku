# DizzDer — Portfolio Reload

Портфолио Қанатұлы Қуат в эстетике меню Persona 3 Reload. Дизайн воспроизводит видеореференс пользователя: синие анимированные фоны, наклонные заголовки, красное выделение выбранного пункта и круговые переходы.

**Сайт:** https://dizzder.github.io/mywebku/

## Возможности

- Главное меню PROJECT / SKILLS / ABOUT / CONTACT. Мышь, касание и клавиатура: ↑/↓, Enter, Escape.
- Девять существующих проектов, фильтры и диалоги с описаниями и ссылками на исходники.
- Четыре категории навыков с управлением стрелками ←/→, Home и End. Навыки связаны с проектами; числовые оценки владения не выдумываются.
- Сохранены имя, GitHub, Telegram и email. Копирование email с ручным fallback.
- Вход с музыкой **Last Surprise — Lyn / Persona 5** или без неё. Используется официальный релиз в видимом YouTube-плеере. Кнопка ♫ включает/останавливает музыку; закрытие плеера также останавливает её. MP3 не извлекается и не распространяется.
- Звук запускается после действия посетителя. При блокировке браузером плеер предлагает нажать ▶. Нужна доступность YouTube; есть прямая ссылка на трек.
- Адаптив от 320 px, постеры при недоступном видео, остановка фоновых видео на скрытых экранах и в фоновой вкладке, пауза анимаций и prefers-reduced-motion.
- Без JavaScript проекты, навыки, профиль и контакты доступны на обычной странице.

## Запуск и проверка

Статический сайт без сборки и runtime-зависимостей:

```sh
python -m http.server 8000
node --check app.js
node --test tests/site.test.cjs
```

GitHub Pages: `main`, корень `/`. Локальные ресурсы используют относительные пути и работают в `/mywebku/`.

## Структура

- `index.html` — экраны и контент.
- `styles.css` — геометрия, адаптив и состояния.
- `app.js` — данные проектов, навигация, диалоги, видео и YouTube API.
- `assets/scenes/` — сжатые немые видео и WebP-постеры.
- `docs/design.md` — референсы и источники графики/музыки.
- `docs/validation.md` — результаты проверки.
